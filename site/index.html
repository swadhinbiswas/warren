Why Warren?

Run the same app many times with different accounts, configs, and data.

🔒

Total Isolation

Each instance gets its own HOME, config, cache, data, and tmp directories. Nothing leaks between instances.

🎭

Unlimited Aliases

Install the same tool as many times as you want with different names. gh-work, gh-personal, gh-side.

🖥️

GUI App Wrapping

Run two Discords, two Firefox profiles, two VS Code instances — each with separate logins and data.

🚫

Rootless by Design

Warren refuses to run as root. No sudo, no daemons, no containers. Just a thin bash launcher.

⚡

Zero Overhead

No VMs, no containers, no background processes. Startup overhead is under 50ms.

🐚

Universal Shell

Works with Bash, Zsh, Fish, and Nushell. Auto-detects and configures your PATH.

How it Works

Three simple levers achieve total isolation.

1

Intelligent Rewriting

Warren intercepts installer scripts and rewrites hardcoded paths (/usr/local/bin, ~/.config) to point inside the instance's private directory.

2

Environment Injection

A lightweight launcher overrides $HOME, $XDG_CONFIG_HOME, $XDG_DATA_HOME, and $TMPDIR before running your tool.

3

Execution

The application boots entirely unaware that its "home directory" is a sandbox inside ~/.warren/.

See it in Action

Two GitHub CLIs, two accounts, zero conflicts.

Terminal
$ warren dig gh --as gh-work ✓ Installed: gh-work ✓ Launcher: ~/.local/bin/gh-work $ warren dig gh --as gh-personal ✓ Installed: gh-personal ✓ Launcher: ~/.local/bin/gh-personal $ gh-work auth login ✓ Logged into github.com as @work-account $ gh-personal auth login ✓ Logged into github.com as @personal-account
Desktop
$ warren dig flatpak:com.discordapp.Discord --as discord-work ✓ Wrapped: discord-work (Discord account #1) ✓ Desktop entry created $ warren dig flatpak:com.discordapp.Discord --as discord-home ✓ Wrapped: discord-home (Discord account #2) ✓ Desktop entry created $ warren ls ALIAS APP VERSION KIND discord-work discord - gui discord-home discord - gui gh-work gh 2.4.0 cli gh-personal gh 2.4.0 cli

Install Warren

One line. No dependencies beyond curl.

One-Liner (Recommended)

Downloads a pre-built binary or builds from source if needed.

$ curl -fsSL https://warren.run/install.sh | bash

Cargo

If you already have Rust installed.

$ cargo install warren-cli
$ warren shell install
